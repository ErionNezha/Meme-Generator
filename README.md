# 😂 Gjenerator Memesh

Krijo meme qesharake me shabllone të vizatuara, tekstin tënd sipër/poshtë — ose ngarko foton tënde.

Gjenerator memesh 100% në browser — zgjidh shabllonin, shkruaj tekstin, shkarko PNG-në.

## ✨ Veçori

- 🎭 6 shabllone të vizatuara (gradient + emoji gjigante)
- ✍️ Tekst sipër / poshtë me stil klasik meme (outline i trashë)
- 🔠 Madhësi e rregullueshme e shkronjave (24–120 px)
- 🎨 Ngjyrë e personalizueshme e tekstit
- 🖼️ Ngarko foton tënde si sfond (JPG/PNG)
- ⬇️ Shkarkim si PNG (`meme.png`, 600×600)
- 📱 Plotësisht responsive
